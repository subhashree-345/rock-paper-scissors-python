# Rock Paper Scissor Game

A simple command-line Rock Paper Scissor game built with Python.

## Features

* User vs Computer gameplay
* Random computer moves
* Win/Lose/Tie detection
* Beginner-friendly Python project

## Technologies Used

* Python 3
* Random Module

## How to Run

1. Clone the repository

```bash
git clone https://github.com/yourusername/rock-paper-scissor-python.git
```

2. Navigate to the project folder

```bash
cd rock-paper-scissor-python
```

3. Run the program

```bash
python game.py
```

## Example

```text
Enter your move = Rock, Paper, Scissor = Paper

User choice = Paper
Computer choice = Rock

Paper covers Rock = You win
```
